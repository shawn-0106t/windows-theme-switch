# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately via
[GitHub private vulnerability reporting](https://github.com/shawn-0106t/windows-theme-switch/security/advisories/new).

- Do **not** open a public issue for security problems.
- Include reproduction steps and affected commit/version when possible.
- You should receive a response within a few days.

This project only manipulates current-user registry keys (`HKCU`) and does not
handle credentials or network input, so the attack surface is minimal — but
reports are still welcome and appreciated.
